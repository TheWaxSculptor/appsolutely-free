Free alternatives to Raycast Pro / Alfred Powerpack

Raycast Pro / Alfred Powerpack by Raycast / Running with Crayons costs: money. These 3 free apps (many open source) can replace it, with screenshots, pros, and cons.

Ulauncher

GPL-3.0 ✓ Last checked: 2026-10
Open source $0 to use
Linux

A fast, minimal application launcher for Linux written in Python and GTK with customizable themes and extensive extension support.

ReplacesRaycast Pro / Alfred Powerpack

Pros

  • Blazingly fast search for apps, files, and browser bookmarks
  • Rich extension ecosystem for GitHub, Spotify, dictionary, and calculations
  • Lightweight and native to Linux desktop environments

Cons

  • Linux only
  • Simpler interface than Raycast with no window tiling manager
Switching: easy

Flow Launcher

MIT ✓ Last checked: 2026-10
Open source $0 to use
Windows

A modern, open-source file search and productivity launcher for Windows with instant Everything search integration and rich plugins.

ReplacesRaycast Pro / Alfred Powerpack

Pros

  • Integrates seamlessly with Everything search for sub-second file retrieval
  • Execute shell commands, calculate math, and search browser tabs instantly
  • Fully customizable themes and community plugin store

Cons

  • Windows only
  • Plugin quality varies between community authors
Switching: easy

Albert Launcher

GPL-3.0 ✓ Last checked: 2026-10
Open source $0 to use
Linux

A lightning-fast, C++ and Qt-powered keyboard launcher for Linux with minimal resource consumption and modular plugins.

ReplacesRaycast Pro / Alfred Powerpack

Pros

  • Negligible CPU and RAM footprint written in native C++
  • Extensible with Python and C++ plugins
  • Fuzzy search across system apps, files, and mathematical expressions

Cons

  • Linux only
  • Configuration requires manual plugin toggling in settings
Switching: easy
