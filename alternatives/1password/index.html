Free alternatives to 1Password

1Password by AgileBits costs: Subscription. These 5 free apps (many open source) can replace it, with screenshots, pros, and cons.

Bitwarden

14k GPL-3.0 ✓ Last checked: 2026-10
Open source $0 to use
WebWindowsMacLinuxiPhone / iPadAndroid

An open-source password manager with a generous free plan and apps everywhere.

Replaces1PasswordLastPass

Pros

  • Free unlimited passwords on all devices
  • Open-source and audited
  • Self-hostable server

Cons

  • Interface is functional rather than fancy
  • Some features are premium
Switching: easy
Source code Get Bitwarden

KeePassXC

29k GPL-3.0 ✓ Last checked: 2026-10
Open source $0 to use
WindowsMacLinux

A local, offline password manager that stores everything in an encrypted file you control.

Replaces1PasswordLastPass

Pros

  • Fully offline and private
  • Browser integration and TOTP
  • No account or cloud

Cons

  • You handle syncing yourself
  • No official mobile app
Switching: moderate
Source code Get KeePassXC

Proton Pass

Free tier, paid plans ✓ Last checked: 2026-10
Limited free plan
WebiPhone / iPadAndroidWindowsMacLinux

An open-source, end-to-end encrypted password manager with hide-my-email aliases.

Replaces1PasswordLastPass

Pros

  • Unlimited passwords on the free plan
  • Built-in email aliases and 2FA codes
  • Open-source and audited

Cons

  • Some features need a paid plan
  • Younger than Bitwarden and 1Password
Switching: easy
Get Proton Pass

Passbolt

6.2k AGPL-3.0 ✓ Last checked: 2026-10
Open source $0 to use
WindowsMacLinuxiPhone / iPadAndroidWeb

An open-source password manager designed for agile teams and businesses with granular sharing permissions and OpenPGP cryptography.

Replaces1PasswordLastPass

Pros

  • Granular folder and credential sharing permissions for teams
  • Full OpenPGP end-to-end encryption verified by third-party audits
  • Free Community Edition can be self-hosted in your own infrastructure

Cons

  • Designed specifically for team sharing rather than solo consumers
  • Self-hosting requires standard Docker or Linux server installation
Switching: moderate
Source code Get Passbolt

Vaultwarden

69k AGPL-3.0 ✓ Last checked: 2026-10
Open source Requires hosting/hardware
WindowsMacLinuxiPhone / iPadAndroidWeb

A lightweight, self-hosted Bitwarden-compatible backend server written in Rust that runs on minimal RAM and unlocks Bitwarden Premium features.

Replaces1PasswordLastPass
⚠️
Important limitation: Requires user-managed server, Docker, or hosting infrastructure.

Pros

  • Drop-in replacement for Bitwarden server using tiny CPU and RAM resources (ideal for Raspberry Pi)
  • Compatible with all official Bitwarden browser extensions and mobile apps
  • Unlocks premium 2FA features (TOTP generation) and file attachments for free

Cons

  • Requires basic Docker knowledge to host and maintain
  • You are responsible for backing up your SQLite/Postgres database
Switching: moderate
Source code Get Vaultwarden
