Free alternatives to GoodNotes / Notability

GoodNotes / Notability by Time Base Technology / Ginger Labs costs: money. These 3 free apps (many open source) can replace it, with screenshots, pros, and cons.

Xournal++

15k GPL-2.0 ✓ Last checked: 2026-10
Open source $0 to use
WindowsMacLinux

An open-source handwriting note-taking application with PDF annotation, pressure-sensitive stylus support, and audio recording.

ReplacesGoodNotes / Notability

Pros

  • Annotate and highlight imported PDF textbooks and documents smoothly
  • Pressure-sensitive pen and stylus support with palm rejection
  • Audio recording synced to your handwritten notes

Cons

  • Interface is designed as a desktop application with classic toolbars
  • Mobile Android port is unofficial/in-progress
Switching: easy
Source code Get Xournal++

Rnote

12k GPL-3.0 ✓ Last checked: 2026-10
Open source $0 to use
LinuxWindowsMac

A vector-based sketch and handwritten note-taking app designed for drawing tablets and touchscreens with smooth infinite canvas.

ReplacesGoodNotes / Notability

Pros

  • Infinite canvas with vector rendering keeps handwriting crisp at any zoom
  • Shape recognition turns rough sketches into perfect circles and rectangles
  • Exports to SVG, PDF, and Xopp with full vector fidelity

Cons

  • Best on Linux and GNOME touchscreens (Windows build is newer)
  • No direct cloud sync client built into the app
Switching: easy
Source code Get Rnote

Saber

4.9k GPL-3.0 ✓ Last checked: 2026-10
Open source $0 to use
WindowsMacLinuxiPhone / iPadAndroidWeb

An open-source handwritten notes app designed for tablets and phones with dark mode inverted ink and Nextcloud synchronization.

ReplacesGoodNotes / Notability

Pros

  • Dark mode inverts colors dynamically so handwriting doesn’t blind you at night
  • Cross-platform sync via Nextcloud or custom WebDAV servers
  • Password protect sensitive notebooks with local encryption

Cons

  • Younger project with fewer template options than GoodNotes
  • Tool selection is focused on writing essentials
Switching: easy
Source code Get Saber
