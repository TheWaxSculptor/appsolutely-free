Screenity

GPL-3.0 ✓ Last checked: 2026-10
Open source $0 to use
Web

A feature-packed open-source screen recorder and annotation tool for Chrome with webcam overlay, zoom, drawing, and trimming.

ReplacesLoom / ScreenFlowSnagit

Pros

  • Unlimited recordings with zero watermarks or time limits
  • Annotate your screen live with pens, arrows, text, and click highlights
  • Save directly to Google Drive or export as MP4/WebM/GIF

Cons

  • Requires a Chromium-based browser (Chrome, Brave, Edge)
  • Desktop recording outside the browser relies on OS screen sharing permission
Switching: easy
Source code Get Screenity

Shottr

Free personal use, $12 Pro ✓ Last checked: 2026-10
Limited free plan
Mac

A tiny, 1.6MB pixel-perfect screenshot utility for macOS with scrolling capture, OCR text extraction, pixel ruler, and blur tools.

ReplacesSnagit
⚠️
Important limitation: macOS only; periodic dialog asks to support the developer with a $12 optional license.

Pros

  • Blazingly fast startup taking less than 15ms to trigger
  • Scrolling screenshot capture for long web pages and chat logs
  • Instant OCR extracts text or QR codes directly from screenshots

Cons

  • macOS only
  • Occasional banner prompt to upgrade to the $12 Pro supporter tier
Switching: easy
Get Shottr

Kap

MIT ✓ Last checked: 2026-10
Open source $0 to use
Mac

An open-source macOS screen recorder built on web standards that exports silky-smooth video to MP4, GIF, and WebM with custom plugins.

ReplacesLoom / ScreenFlowSnagit

Pros

  • Clean, unobtrusive menu bar interface with simple capture crop
  • Export directly to GIF or MP4 with adjustable framerates and dimensions
  • Extensible plugin system for uploading to S3, Streamable, or Imgur

Cons

  • macOS only
  • Built with Electron, so slightly higher memory footprint during active recording
Switching: easy
