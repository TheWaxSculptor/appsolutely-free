GPL-3.0 ✓ Last checked: 2026-10
Open source Requires hosting/hardware

An open-source web application that turns any existing PostgreSQL database into an intuitive spreadsheet UI for non-technical users.

ReplacesAirtable
⚠️
Important limitation: Requires user-managed server, Docker, or hosting infrastructure.
