Free alternatives to Firebase

Firebase by Google costs: Usage-based beyond free tier. These 3 free apps (many open source) can replace it, with screenshots, pros, and cons.

Supabase

111kApache-2.0
Open source
WebSelf-Hosted

An open-source Firebase alternative built on Postgres with auth, storage, and realtime.

ReplacesFirebase

Pros

  • Real Postgres database
  • Auth, storage, and realtime included
  • Can be self-hosted

Cons

  • Self-hosting has many moving parts
  • Different data model than Firestore
Switching: moderate

Appwrite

58kBSD-3-Clause
Open source
WebSelf-Hosted

An open-source backend server with auth, databases, storage, and functions.

ReplacesFirebase

Pros

  • Broad SDK support
  • Simple Docker-based self-hosting
  • Auth and storage included

Cons

  • Ecosystem is younger than Firebase
  • Realtime features are less mature
Switching: moderate
Source code Get Appwrite

PocketBase

61kMIT
Open source
Self-Hosted

An open-source backend in a single file with database, auth, file storage, and an admin UI.

ReplacesFirebase

Pros

  • Single executable, trivial to deploy
  • Realtime subscriptions and auth
  • Admin dashboard included

Cons

  • SQLite-based, so it is not for huge scale
  • Pre-1.0 so APIs can change
Switching: easy
