Free alternatives to Spotify Premium

Spotify Premium by Spotify costs: money. These 3 free apps (many open source) can replace it, with screenshots, pros, and cons.

Spotube

50kBSD-4-Clause
Open source
WindowsMacLinuxiPhone / iPadAndroidWeb

An open-source Spotify client that uses Spotify’s metadata with YouTube as the audio source, giving you ad-free music.

ReplacesSpotify Premium

Pros

  • No Spotify Premium subscription needed
  • No ads and no telemetry
  • Download tracks for offline listening

Cons

  • Relies on YouTube audio matching, so very niche live tracks may mismatch
  • Cannot play Spotify Podcasts
Switching: easy

Open source

The legendary free media player that plays virtually any video, audio, DVD, or stream format without codec packs.

ReplacesSpotify PremiumPlex

Pros

  • Plays absolutely every video and audio codec known to man
  • Zero ads, spyware, or user tracking
  • Hardware acceleration and streaming support

Cons

  • Traditional media player UI rather than a cloud library
  • Does not provide cloud music catalogs
Switching: easy
Source code Get VLC Media Player

Nuclear Music Player

19kAGPL-3.0
Open source
WindowsMacLinux

A modern streaming music player that pulls free music from free sources across the internet into one slick UI.

ReplacesSpotify Premium

Pros

  • Free streaming with no ads
  • Scrobbling to Last.fm and lyrics integration
  • Multi-source searching

Cons

  • Electron-based, so can use more RAM than native apps
  • Track matching occasionally differs
Switching: easy
