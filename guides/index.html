Adobe Photoshop ➔ Photopea / GIMP

Switching from Photoshop to Photopea or GIMP

How to keep your .PSD files, layers, masks, and keyboard shortcuts.

📂 Opens Native: .PSD, .TIFF, .PNG, .JPG, .WEBP, .RAW
💾 Exports To: .PSD, .PNG, .JPG, .SVG, .PDF, .WEBP

Transition Steps:

1. Opening Existing Photoshop Files

Photopea opens multi-layer .PSD files directly with smart objects, adjustment layers, clipping masks, and layer styles intact. GIMP 2.10+ opens .PSD files with standard raster layers, layer masks, and blending modes.

2. Matching Photoshop Keyboard Shortcuts

Photopea comes preconfigured with standard Photoshop shortcut keys (V for Move, B for Brush, Cmd/Ctrl+J to Duplicate, Cmd/Ctrl+T to Transform). In GIMP, go to Edit → Keyboard Shortcuts or download the 'Photoshop Shortcuts for GIMP' profile.

3. Replicating Photoshop Action & Filter Workflows

Install G'MIC (GREYC's Magic for Image Computing) in GIMP for over 500 filters including neural style transfer, film grain emulation, and frequency separation.

⚠️ Critical Gotchas & Workarounds:

Adobe proprietary adjustment layers (e.g. Color Lookup Tables with 3D LUTs) or proprietary Cloud Smart Objects may flatten in GIMP. Export key assets as high-resolution layered PSDs or TIFFs before cancelling Adobe Creative Cloud.

Microsoft 365 (Word, Excel, PowerPoint) ➔ LibreOffice (Writer, Calc, Impress)

Switching from Microsoft 365 to LibreOffice

Preserving document formatting, Excel formulas, and slide transitions.

📂 Opens Native: .DOCX, .XLSX, .PPTX, .DOC, .XLS, .PPT, .CSV, .ODT, .ODS, .ODP
💾 Exports To: .DOCX, .XLSX, .PPTX, .PDF, .ODT, .ODS, .EPUB

Transition Steps:

1. Avoiding Font Substitution Layout Shifts

Layout shifts when opening .docx in LibreOffice are almost always caused by missing Microsoft proprietary fonts (Calibri, Aptos, Cambria). Install the Carlito and Caladea metric-compatible fonts (or standard Microsoft Core Fonts), and documents render with pixel-accurate line wraps.

2. Setting Default Save Formats to Microsoft .docx/.xlsx

If you collaborate with Office users, set LibreOffice default format: Tools → Options → Load/Save → General → Always save as Word 2010-365 (*.docx) and Excel 2010-365 (*.xlsx).

3. Excel Formulas and Pivot Tables

LibreOffice Calc provides broad formula compatibility with Excel (including VLOOKUP, XLOOKUP, INDEX/MATCH, and SUMIFS). Pivot Tables (Data → Pivot Table) support standard data aggregation. Note: Highly complex nested formulas, proprietary VBA macros, and Power Pivot models require Microsoft Excel. (Source: The Document Foundation Calc Documentation, verified October 2026).

⚠️ Critical Gotchas & Workarounds:

Complex Visual Basic for Applications (VBA) macros with proprietary Windows ActiveX controls require reviewing or porting to LibreOffice Basic or Python scripting.

Notion ➔ Obsidian

Switching from Notion to Obsidian

Liberating your personal database and notes into local Markdown files you own forever.

📂 Opens Native: .MD (Markdown), .CSV, .JSON, .CANVAS, images, audio, PDF
💾 Exports To: Plaintext Markdown, HTML, PDF

Transition Steps:

1. Exporting Your Notion Workspace

In Notion, click Settings & Members → Settings → Export all workspace content → Select 'Markdown & CSV' with 'Include subpages' enabled. Download the generated ZIP file.

2. Importing into an Obsidian Vault

Create a new Obsidian Vault pointing to a local folder on your computer. Use the official 'Notion Importer' community plugin in Obsidian (Settings → Community Plugins → Importer → Notion) to convert Notion databases and callouts into clean Markdown with embedded images.

3. Replicating Notion Databases & Kanban Boards

Install the community 'Dataview' and 'Kanban' plugins in Obsidian. Dataview enables SQL-like queries across your notes (e.g. status = 'in progress', due_date < date(today)), rendering instant interactive tables.

⚠️ Critical Gotchas & Workarounds:

Notion's nested page URLs will become local wikilinks [[Page Name]]. Complex relational formulas should be set up via Obsidian Dataview or the Projects plugin.

1Password / LastPass ➔ Bitwarden

Switching from 1Password or LastPass to Bitwarden

Zero-downtime password migration with end-to-end zero-knowledge encryption.

📂 Opens Native: 1Password (.1pux, .csv), LastPass (.csv), Chrome/Firefox (.csv), KeePass (.kdbx)
💾 Exports To: Encrypted JSON, Standard JSON, CSV

Transition Steps:

1. Export Vault from Old Manager

In 1Password, choose File → Export → All Items (.1pux or .csv). In LastPass, go to Advanced Options → Export → Enter Master Password → Save as CSV.

2. Import Directly into Bitwarden

Log in to vault.bitwarden.com → Tools → Import Data → Select '1Password (.1pux)' or 'LastPass (csv)' from the dropdown → Select file and click Import. All logins, secure notes, cards, and 2FA seeds transfer in seconds.

3. Permanently Shred the Unencrypted Export

CRITICAL: The exported .csv file contains plaintext passwords. After confirming everything is visible in Bitwarden, immediately shred/delete the export file from your downloads folder and empty trash.

⚠️ Critical Gotchas & Workarounds:

Disable browser password autofill in Chrome/Safari to prevent conflicting double-autofill popups.

Adobe Premiere Pro ➔ DaVinci Resolve

Switching from Premiere Pro to DaVinci Resolve

Exporting timelines, XML projects, and switching to industry-standard color grading.

📂 Opens Native: FCP XML (.xml), EDL, AAF, MP4, MOV, Apple ProRes, Blackmagic RAW, Sony/Canon RAW
💾 Exports To: ProRes, H.264, H.265, QuickTime, IMF, DCP, Final Cut XML

Transition Steps:

1. Exporting XML from Premiere

In Premiere Pro, select your active sequence → File → Export → Final Cut Pro XML (*.xml). This exports edit cuts, track positions, volume points, and clip timing.

2. Importing XML Timeline into Resolve

In DaVinci Resolve, go to File → Import → Timeline → Select your exported XML file. Resolve automatically reconnects cuts, track positions, and standard crossfades. Note: Proprietary Premiere Motion effects, Essential Graphics mogrts, and third-party effects must be manually rebuilt. (Source: Blackmagic Design Resolve Reference Manual, verified October 2026).

3. Switching Keyboard Shortcuts to Premiere Layout

Go to DaVinci Resolve → Keyboard Customization → Top right dropdown → Select 'Adobe Premiere Pro'. All your muscle memory (C for Razor cut, Q/W for ripple trim, J-K-L shuttle) transfers seamlessly.

⚠️ Critical Gotchas & Workarounds:

Third-party Adobe After Effects dynamic links or proprietary Premiere plugins (e.g. Essential Graphics templates) should be rendered out as ProRes/DNxHR clips prior to XML export.
