LilyPond

GPL-2.0 ✓ Last checked: 2026-10
Open source $0 to use
WindowsMacLinux

A music engraving system dedicated to producing the highest publication-quality sheet music from automated code input.

ReplacesSibelius

Pros

  • Engraving quality matches the finest traditional European music publishers
  • Text-based music files can be version-controlled in Git
  • Automated spacing, beams, and collision avoidance

Cons

  • Steep learning curve (text programming language, no visual piano roll)
  • Requires a front-end like Frescobaldi for visual previews
Switching: hard
Get LilyPond
